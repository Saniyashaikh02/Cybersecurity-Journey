## Overview

This project documents my SkyTower cybersecurity lab, focusing on reconnaissance, service enumeration, vulnerability assessment, and security reporting.

## Objectives

- Understand the lab's network and exposed services.
- Practice reconnaissance and enumeration.
- Identify and assess potential security weaknesses.
- Document evidence and verified findings.
- Recommend appropriate security improvements.

## Methodology

1. Define the authorized testing scope.
2. Perform reconnaissance.
3. Enumerate ports and services.
4. Analyze potential vulnerabilities.
5. Validate findings in the lab environment.
6. Document evidence, risks, and remediation.
