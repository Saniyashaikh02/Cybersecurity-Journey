**Author:** Saniya Shaikh  
**Domain:** Vulnerability Assessment and Penetration Testing  
**Lab Type:** Capture The Flag (CTF)  
**Status:** In Progress

## Overview

This project documents my work on the Who Wants to Be King cybersecurity lab, including reconnaissance, enumeration, vulnerability analysis, and security reporting.

## Objectives

- Practice systematic reconnaissance and enumeration.
- Identify potential security weaknesses in the lab.
- Validate findings within the authorized environment.
- Document evidence and assess security risks.
- Recommend remediation for identified vulnerabilities.

## Methodology

1. Define the authorized lab scope.
2. Perform reconnaissance.
3. Enumerate available services.
4. Analyze potential vulnerabilities.
5. Validate findings in the lab.
6. Document results and remediation recommendations.
