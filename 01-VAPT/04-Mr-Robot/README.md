**Lab Type:** Capture The Flag (CTF)

## Overview

This project documents my Mr. Robot penetration-testing lab, including reconnaissance, enumeration, vulnerability analysis, and verified findings.

## Objectives

- Practice network and service reconnaissance.
- Explore web application attack surfaces.
- Identify and validate security weaknesses in the lab.
- Document evidence, findings, and remediation recommendations.

## Methodology

1. Confirm the authorized lab scope.
2. Perform reconnaissance and enumeration.
3. Identify potential vulnerabilities.
4. Validate findings within the lab environment.
5. Record evidence and assess risks.
6. Recommend appropriate remediation.
