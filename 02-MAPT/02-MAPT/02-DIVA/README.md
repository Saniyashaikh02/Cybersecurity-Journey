**Platform:** Android

## Overview

DIVA (Damn Insecure and Vulnerable App) is an intentionally vulnerable Android application used for learning mobile application security.

This project documents my static analysis work and security observations.

## Assessment Objectives

- Review application structure and configuration.
- Identify potential weaknesses in code and data handling.
- Understand Android security risks.
- Document findings and remediation recommendations.
