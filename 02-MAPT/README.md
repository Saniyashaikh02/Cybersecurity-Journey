# 📱 Mobile Application Penetration Testing (MAPT)

**Author:** Saniya Shaikh  
**Domain:** Mobile Application Security  
**Focus:** Android Security Assessment

## Overview

This section documents my mobile application security learning, static analysis reports, and practical security assessments of intentionally vulnerable Android applications.

## Objectives

- Understand Android application architecture and security.
- Learn Static Application Security Testing (SAST).
- Identify insecure configurations and potential vulnerabilities.
- Explore application permissions, storage, and data protection.
- Document findings and recommend remediation.

## Tools & Technologies

- **MobSF** — Mobile Security Framework
- **JADX** — Android application decompiler
- **APKTool** — APK resource analysis
- **Frida** — Dynamic instrumentation
- **Objection** — Mobile application security testing
- **Burp Suite** — Application traffic analysis
- **Android Debug Bridge (ADB)** — Android device interaction
